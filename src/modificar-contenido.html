Modificar el contenido HTML

JavaScript permite cambiar el contenido de los elementos HTML cuando el usuario realiza una acción.

Ejemplo práctico

Este texto cambiará al pulsar el botón.

¿Cómo funciona?

getElementById() busca un elemento por su identificador. innerHTML cambia su contenido y onclick ejecuta la acción cuando pulsamos el botón.
